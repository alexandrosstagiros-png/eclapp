# Связанные данные для планирования

`import-local.cjs` читает исходные CSV «Массив» и «Машины», сохраняет реквизиты отдельно от аккаунтов и предоставляет их через защищённый `/planning/options`. Получатель должен иметь `personal_data_visible` для выбранной области. Никакие номера документов не попадают в отчёт импорта.

Два режима:

- `--scope UUID` сопоставляет только доступные в области действующие записи: уникальное полное ФИО или точный госномер. При различающемся телефоне профиля, повторном ФИО/номере в файле или неоднозначном совпадении импорт пропускает запись. Повторные ссылки на один UUID машины не считаются разными машинами.
- `--standalone --create-scope` создаёт отдельный проект «Планирование · справочник из файла» и область «Водители и транспорт» в организации и регионе существующего локального администратора. Единственное новое право получает этот администратор. Записи водителей и машин принадлежат только планированию: аккаунты, водительские разрешения, рабочие рейсы и связи 1С не создаются. `--standalone --scope UUID` использует указанную уже существующую область.

Без `--apply` все действия выполняются в откатываемой транзакции, отчёт содержит только числа. С `--apply` перенос фиксируется атомарно. CLI подключается только к базе локального приложения на этом Mac через `integrations/local-app/runtime.cjs`.

```sh
node integrations/planning-catalog/import-local.cjs \
  --standalone --create-scope \
  --drivers '/полный/путь/Массив.csv' \
  --vehicles '/полный/путь/Машины.csv'
```

Для применения добавьте `--apply`. Сначала должна быть установлена миграция `060_planning_resource_data.sql`. Исходные файлы не изменяются. Для каждой загруженной записи сохраняются имя файла, SHA-256 и номер строки CSV. Идентификаторы записей устойчивы к повторному импорту; повтор неизменённого файла не дублирует справочник. Импорт не удаляет ранее загруженные записи, отсутствующие в новом файле, и не активирует ранее отключённые.

В доступной копии исходных файлов обнаружены 490 строк с ФИО и 309 строк с госномером. Для отдельного справочника пригодны 476 водителей и 300 машин: 8 неполных ФИО и 2 некорректных номера не используются как ключи, ещё 6 строк водителей и 7 строк машин пропускаются из-за повторяющихся ключей. Пустые и технические строки не создают записи. Совпадений с существующими учебными справочниками и локальной 1С не найдено.

Паспорт и водительское удостоверение сохраняются целым исходным текстом. Серия, номер, дата и орган выдачи не угадываются из свободного текста. Адрес проживания и регистрации хранятся отдельно. Дата рождения принимается только в точном формате `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`, с проверкой календаря. Реквизиты медкнижки не выводятся из неоднозначных колонок «врачи» и «аттестация». Грузоподъёмность в кг вычисляется только при явно написанной единице `кг` или `т`; исходный текст сохраняется как отдельная грузоподъёмность. Пропуски и ошибки Excel остаются незаполненными, их можно дополнить в строке плана.
