# Полное приложение ЕЦЛ на этом Mac

Постоянный адрес: **http://127.0.0.1:18514**. Локальное приложение использует обычные разделы ЕЦЛ, включая планирование и календарь, и сохраняет изменения после перезапуска. Первый запуск создаёт учебный проект и локального администратора. Привязку к существующей базе 1С выполняет отдельный локальный модуль обмена.

Из корня проекта:

```sh
node integrations/local-app/manage.cjs start
node integrations/local-app/manage.cjs status
node integrations/local-app/manage.cjs stop
```

`start` запускает приложение в фоне и проверяет HTTP-готовность до 150 секунд; каждые 30 секунд сообщает, что запуск продолжается. До запуска API обновляются справочники существующей локальной 1С (ожидание — до двух минут). Если 1С недоступна, приложение запускается с сохранёнными данными и связями, а причина записывается в журнал. Логи: `.local/local-app/launcher.log`. Повторный запуск не сбрасывает данные и доступы. `stop` закрывает приложение и его PostgreSQL; каталог базы сохраняется. Для запуска двойным щелчком доступны файлы `.command` в этом каталоге.

## Планирование → 1С

1. Откройте «Планирование» и нужную дату. Сохранённые планы находятся автоматически; для нового назначения выберите водителя. Связь со справочниками InfoBase определяется по данным назначения, без переключателя технических проектов.
2. В плане дня добавьте водителя, автомобиль, время выхода, статус «В работе», один рейс. В «Календаре» можно редактировать и копировать назначения на другие даты.
3. Сохраните план или календарь. Выберите назначения флажками «В 1С» либо выделите нужные ячейки/дни календаря.
4. Нажмите **«Передать в 1С»**. Приложение покажет результат каждой строки, номер заявки и смены. До 200 назначений за одну отправку.

Одна рабочая строка создаёт одну связанную `ЗаявкаКлиента` и `СменаТранспорта` с водителем, машиной, клиентом, проектом, датой и плановым временем. Комментарий — до 800 символов. В конфигурации поле планового времени смены хранит только дату; часы сохраняются в реквизитах времени заявки и комментарии смены. Отметки фактического выхода, прибытия и проведения не выставляются. Дополнительные поля клиентских форм пока не сопоставлены: заполненные поля вызывают явную ошибку строки, чтобы не потерять данные. Резерв/отмены и несколько рейсов в одной строке также требуют отдельного сценария обмена.

Повтор тех же данных проверяет существующие документы без дублей. Незавершённая отправка возобновляется по тем же UUID. После редактирования уже отправленного назначения приложение покажет расхождение: автоматическое изменение/удаление документов 1С пока не выполняется. Новая строка означает новую смену, поэтому сначала сверьте предыдущий документ. Квитанции, планы и очередь обмена сохраняются между перезапусками.

Источником остаётся **самописная локальная InfoBase**. Рабочие ТЛЭиУАТ и КА 2 ещё не подключены; для них нужно отдельное сопоставление документов и полей. `source_namespace` и файлы `.local/local-app/one-c-namespace.json` сохраняют идентичность обмена: не удаляйте их при обычном перезапуске.

Проверка на реальной базе 20.09.2026: через интерфейс создана учебная смена на **21.09.2026 09:00**, заявка **DORD0003**, смена **DSHF0003**. Повтор из плана дня и календаря подтвердил те же UUID; в базе осталось по три заявки/смены (две прежние и одна новая). Факт выхода и проведение — выключены. Тестовая строка помечена комментарием «ЛОКАЛЬНЫЙ ТЕСТ ЕЦЛ». Полный результат — `.local/local-app/live-verification.json`.

Справочники обновляются при запуске приложения. Для обновления без перезапуска:

```sh
node integrations/one-c-local/import-planning.cjs
```

После этого обновите страницу. Сервер 1С автоматически поднимается при старте и при попытке отправки.

## Данные для входа

Телефон локального администратора: `+79990000001`. Случайный пароль создаётся один раз и хранится в `.local/local-app/login.json` с правами `0600`. Вход выполняется обычной формой по телефону и паролю. Пароль не выводится в журнал и не передаётся в URL. Если пароль изменён в самом приложении, ранее сохранённый пароль в этом файле больше не действует.

```json
{
  "schemaVersion": "transport.local-app.login.v1",
  "url": "http://127.0.0.1:18514",
  "userId": "10000000-0000-4000-8000-000000000005",
  "role": "access_admin",
  "phone": "+79990000001",
  "password": "<сгенерированный локальный пароль>",
  "issuedAt": "<дата выдачи>",
  "localOnly": true
}
```

## Локальное хранение

- `.local/local-app/db/` — постоянная PostgreSQL; доступна только на `127.0.0.1:18515`, база `transport_local`.
- `.local/local-app/credentials.json` — случайные локальные пароли PostgreSQL, права `0600`.
- `.local/local-app/login.json` — начальный пароль локального администратора, права `0600`.
- `.local/local-app/state.json` — состояние процесса без секретов.
- `.local/local-app/launcher.log` — журнал запуска без паролей.

Схема `credentials.json`: `{schemaVersion:'transport.local-app.credentials.v1', createdAt, database:{host:'127.0.0.1',port:18515,name:'transport_local',adminUser:'postgres',adminPassword,appUser:'transport_app',appPassword}}`.

Для локального скрипта настройки связей можно получить административный пул, не выводя пароль:

```js
const { openAdminPool } = require('./integrations/local-app/runtime.cjs');
const pool = await openAdminPool();
try {
  // Параметризованные запросы настройки локальных связей.
} finally {
  await pool.end();
}
```

Все миграции из `recovered/infra/db/migrations/` применяются при запуске. Проверка контрольных сумм защищает уже применённые миграции от незаметного изменения. Начальные учебные записи создаются только до отметки `synthetic_seed_v1` в `local_app_metadata`; повторные запуски их не восстанавливают.

Окружение собирается заново из локальных настроек. Файлы `.env` и рабочие учётные данные не читаются. API использует ограниченную роль `transport_app`. Внешний финансовый обмен, отправка уведомлений, Telegram и MAX выключены. Включён только `LOCAL_ONE_C_ENABLED=true` для локального модуля 1С. Публичного обхода входа и dev-login нет.

Приложение и PostgreSQL слушают только loopback. HTTP отклоняет чужие Host/Origin, а браузерные внешние ресурсы и подключения ограничены CSP. Каталог `.local/` исключён из Git.
