# Приложения ЕЦЛ

Общий клиент Tauri 2 для macOS, Windows, Android и iOS. Rust отвечает за сетевой
транспорт, настройки сервера и сохранение документов; существующий интерфейс ЕЦЛ
входит в приложение. Клиент подключается к общему NestJS API и не содержит базу
данных или сервер 1С.

На этом Mac после сборки можно открыть `Открыть ЕЦЛ.command`: он проверяет запуск
существующей локальной установки, затем открывает `ECL.app`. Обычный запуск
`ECL.app` подключается к уже работающему серверу. Адрес локальной установки —
`http://127.0.0.1:18514`.

## Проверка и сборка

Из корня репозитория установите веб-зависимости: `npm ci --prefix recovered`.
Затем:

```sh
cd native
npm ci
npm run prepare:web
npm test
cargo test --locked --workspace
npm run test:api
npm run build -- --bundles app
```

`test:api` создаёт временные PostgreSQL и API с синтетическими пользователями,
проверяет реальные вход, обновление сессии и выход через Rust. Рабочие реквизиты
не используются.

Подробности для четырёх платформ: [NATIVE_APPS.md](../docs/NATIVE_APPS.md).
Автоматические обновления и выпуск подписанных GitHub Releases: [NATIVE_UPDATES.md](../docs/NATIVE_UPDATES.md).
Сборки CI создают тестовые артефакты без публикации в магазины. Установка iOS на
физический iPhone требует Xcode и настройки подписи Apple. На телефоне адрес
`127.0.0.1` не является адресом вашего Mac.
