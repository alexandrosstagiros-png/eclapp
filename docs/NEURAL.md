# Нейросети

Раздел `Нейросети` (`?section=neural`) объединяет сводки переписки, анализ цен заказ-нарядов, назначение моделей задачам и отчёт расходов. Он доступен сотрудникам с доступом к команде. Настройки моделей и расходы видит и изменяет администратор вне режима входа за сотрудника; анализ цен требует финансового доступа к автопарку.

## Сводка и публикация

Сводки и их ежедневные/еженедельные расписания перенесены из команды. Старые сводки, получатели и расписания сохранены. В команде осталось расписание отчётов по выпуску транспорта.

Администратор выбирает область переписки и период. При локальной обработке сводка выделяет исходные фразы по ключевым словам. При назначенной модели она формирует обзор, а категории и ссылки на источники сохраняют дословные выдержки. При внешнем запросе текст переписки выбранной области передаётся провайдеру; в него могут входить закрытые каналы и личные чаты. Вывод модели требует проверки.

Кнопка `Опубликовать сводку в чат` отправляет текст в выбранный доступный чат своей компании. Повторная публикация той же сводки в тот же чат не создаёт нового сообщения. Публикация требует обычного права писать в чат; архивные чаты и закрытые чаты без участия администратора недоступны. Текст становится доступен аудитории чата; права на исходную переписку не меняются. Отзыв персонального доступа к сводке не удаляет уже опубликованный текст.

В расписании можно выбрать чат для автоматической публикации и отдельных получателей для доступа к сохранённой сводке. Перед запуском сервер повторно проверяет права владельца. Расписание работает на сервере независимо от открытой страницы. Опубликованные сводки исключаются из входных сообщений следующих сводок.

## Анализ цен

Выберите заказ-наряд во вкладке `Анализ цен` и нажмите `Проверить адекватность цен`. Та же проверка доступна в карточках автопарка. Основа — собственная история сопоставимых завершённых заказ-нарядов, минимум три документа за предшествующие 365 дней. Интерфейс показывает медиану, отклонение, основания и нехватку данных. Это не проверка текущих рыночных цен. Подробные правила: [анализ цен](NEURAL_PRICE_ANALYSIS.md).

Назначенная модель добавляет пояснение по подготовленным данным. Если провайдер недоступен, локальное сравнение сохраняется и отображается причина отсутствия комментария.

## Модели и ключи

Настройки сохраняются отдельно для каждой области. До 30 профилей позволяют выбирать разные модели одного или нескольких провайдеров. Для задач `conversation_summary` и `work_order_prices` назначается свой профиль. Локальная обработка не обращается к платным API. В профиле задаются название, точный API ID модели, лимит ответа, валюта и тарифы за миллион входящих/исходящих токенов, чтение и запись кеша. Подсказки моделей не ограничивают свободный ввод идентификатора.

| Провайдер | Серверный секрет | Дополнительно |
| --- | --- | --- |
| OpenAI | `OPENAI_API_KEY` | Chat Completions |
| Anthropic | `ANTHROPIC_API_KEY` | Messages API |
| Qwen | `DASHSCOPE_API_KEY` | Регион профиля; при необходимости `DASHSCOPE_WORKSPACE_ID` |
| GLM | `ZHIPU_API_KEY` | API Z.ai |
| Яндекс | `YANDEX_API_KEY` | `YANDEX_FOLDER_ID` или каталог в профиле |

API-ключи не возвращаются браузеру и не сохраняются в профилях моделей. Интерфейс сообщает только наличие ключа на сервере; это не проверка баланса или доступности конкретной модели. После изменения серверного окружения перезапустите API. Пример переменных: [app.env.example](../deploy/vk-cloud/app.env.example).

Постоянное локальное приложение очищает окружение оболочки. Для него ключи задаются отдельно в `.local/local-app/neural.json` — обычном файле текущего владельца с правами `0600`, до 32 КБ. Структура — JSON-объект с нужными именами переменных из таблицы и строковыми значениями. Неиспользуемые ключи следует опустить. Файл не создаётся автоматически и не включается в Git. После настройки выполните `node integrations/local-app/manage.cjs stop`, затем `node integrations/local-app/manage.cjs start`.

## Расходы

Вкладка `Расходы` показывает выбранный период UTC, число запросов, входящие/исходящие токены, расчётную стоимость, группировку по задачам и моделям, последние 200 запросов. Итоги включают весь период, даже если история сокращена. USD, RUB и CNY учитываются отдельно без придуманного обменного курса.

Токены берутся из ответа провайдера. Тариф фиксируется на момент запроса; последующие изменения настроек не пересчитывают прошлые расходы. Пустой тариф означает неизвестную стоимость, ноль — бесплатные токены. Если нужный тариф кеширования или число токенов неизвестны, деньги не подменяются нулём. Отдельно показаны запросы с неизвестным расходом.

Журнал фиксирует запрос до обращения к провайдеру в независимой транзакции. Успех и ошибка сохраняются даже при откате создания сводки. При тайм-ауте расход может оставаться неизвестным; после аварии процесса незавершённый запрос остаётся в статусе `Выполняется` и требует сверки с провайдером. Расчёт приложения не заменяет счёт провайдера с учётом скидок, налогов и дополнительных услуг. Исходные сообщения, API-ключи и полный текст ответов не пишутся в журнал расходов.

## Проверки и установка

Миграции `070_neural.sql` и `071_neural_summary_publish.sql` добавляют настройки/учёт, метаданные моделей в сводках и идемпотентность публикации. Применяйте штатный мигратор после резервного копирования. Сборка включает новый модуль и стили как в обычный web, так и в локальное приложение.

Из `recovered/`:

```sh
npm run build
npm run test:neural
npm run test:neural:browser
```

Браузерным проверкам нужны Playwright и Chromium (`PLAYWRIGHT_MODULE`, `CHROME_PATH`). Для собранной версии задайте `NEURAL_BUILT_FRONTEND=true`. Проверки работают на временной PostgreSQL и синтетических данных; ключи провайдеров из окружения удаляются. Протоколы пяти API проверяются имитациями ответов; реальных платных запросов тесты не делают.

Установлено в постоянное локальное приложение 28.09.2026. Перед миграциями сохранена и проверена по SHA-256 холодная копия `.local/backups/neural-20260928T105706Z` (2 180 файлов). Количество существующих сообщений, сводок, расписаний, запусков, пользователей и планов не изменилось. Проверены исходная и собранная версии интерфейса, мобильная ширина, сохранение настроек, публикация без дублей и отчёт с несколькими валютами. Общий модульный набор: 376 успешно, 1 предусмотренный пропуск; профильный набор: 27 успешно. Локальная проверка после установки не создавала сообщений и не вызывала внешние модели; протокол — `.local/neural-install-verification.json`.

Протоколы запросов сверены с официальной документацией: [OpenAI](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create), [Anthropic](https://platform.claude.com/docs/en/api/messages/create), [Qwen](https://www.alibabacloud.com/help/en/model-studio/compatibility-of-openai-with-dashscope), [GLM](https://docs.z.ai/api-reference/llm/chat-completion), [Яндекс](https://aistudio.yandex.ru/en/docs/ai-studio/text-generation/api-ref/TextGeneration/completion).
